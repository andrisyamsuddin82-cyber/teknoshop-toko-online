# Gambar Produk Teknoshop

Semua gambar produk pada versi ini disimpan secara lokal di `assets/img/produk/`.
Gambar berupa foto produk bergaya studio yang dibuat khusus untuk katalog contoh,
sehingga tetap tampil tanpa koneksi internet. Nama dan merek produk pada katalog
merupakan nama contoh Teknoshop; gambar menampilkan jenis barang yang sesuai,
bukan klaim foto produk dari merek/model tertentu.

Untuk database yang sudah terpasang, impor `UPDATE_GAMBAR_PRODUK.sql` melalui
phpMyAdmin setelah memilih database `toko_online`. Pastikan folder `assets/`
ikut disalin bersama file website. Foto yang diunggah admin tetap dapat disimpan
secara lokal di `uploads/produk/`.
